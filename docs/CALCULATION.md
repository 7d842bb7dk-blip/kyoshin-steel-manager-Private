# 計算ロジック仕様（CALCULATION）

本システムの重量・単価計算は、元 Excel（`新_鋼材管理Excel.xlsm`）の挙動を忠実に
再現しています。実装は `js/app.js` の `sectionArea()` / `weightKg()` / `unitPrice()` /
`compute()`。**式を変更する場合は本書と Excel の整合を必ず確認してください。**

---

## 1. 全体の流れ

```
入力（材質・鋼種・板厚・材料規格・長さ・表面仕上げ）
   │
   ├─ sectionArea(材質,鋼種,板厚,材料規格)  →  断面積 [mm²]
   │
   ├─ weightKg(...)                         →  重量 [kg]
   │      = round(断面積 × 長さ × 比重 ÷ 1,000,000 , 3)
   │
   ├─ unitPrice(材質,鋼種,表面仕上げ)        →  キロ単価 [円/kg]
   │
   └─ cost                                   →  材料費 [円]
          = round(重量 × キロ単価 , 0)
```

---

## 2. 比重 DENSITY

材質名 → 比重（g/cm³）。

| 材質 | 比重 |
|---|---|
| SUS304 | 7.93 |
| SUS316L | 7.98 |
| SUS430 | 7.7 |
| SS400 | 7.85 |
| SGP | 7.85 |
| STKM | 7.85 |
| A5052 | 2.68 |
| A6063 | 2.7 |

**未登録の材質**は、材質名が `SUS` で始まれば **7.93**、それ以外は **7.85** で代用します。

---

## 3. 寸法の正規化

材料規格の文字列を計算用に整えます。

- `normSpec()` … `Φ`/`φ` を除去し、`×`/`X`/`x` を `*` に変換、前後の空白を除去。
- `dims()` … `*` で分割し、`d1`（1つ目）と `d2`（2つ目、無ければ 0）を取り出す。

例：`Φ48.6` → `48.6`（d1=48.6, d2=0） ／ `75×40` → `75*40`（d1=75, d2=40）

---

## 4. 断面積 sectionArea [mm²]

`板厚 = t`、`寸法 = d1, d2` として、鋼種ごとに以下で算出します。
（π は `Math.PI`）

| 鋼種 | 断面積の式 |
|---|---|
| 丸パイプ(TP-S) / 丸パイプ(TP-A) / サニタリーパイプ | `π/4 × ( d1² − max(d1−2t, 0)² )` |
| 角パイプ | `d1×d2 − max(d1−2t,0) × max(d2−2t,0)` |
| フラットバー | `d1 × t`（幅 × 厚み） |
| アングル | `t × ( d1 + d2 − t )` |
| チャンネル | `t × ( H + 2×耳 − 2t )` ※下記参照 |

- 丸系は「外径 d1・肉厚 t のパイプ」。
- 角パイプは「外形 d1×d2・肉厚 t の角管」。
- チャンネルは Excel の定義に合わせた近似式（`d1=H` 高さ、`d2=耳/フランジ` として実装）。
  実装の係数は `sectionArea()` 内のコメントを参照してください。

> 該当する鋼種が無い／寸法が不正な場合は断面積を求められず、重量・材料費は空欄になります。

---

## 5. 重量 weightKg [kg]

```
重量 = round( 断面積[mm²] × 長さ[mm] × 比重[g/cm³] ÷ 1,000,000 , 3 )
```

- `÷ 1,000,000` は mm³ → cm³ ＋ g → kg の単位換算。
- 小数第 3 位で四捨五入（`round(v, 3)`）。

---

## 6. キロ単価 unitPrice [円/kg]　★最重要

Excel の **SUMIFS と同じ挙動**で、「条件に一致する単価マスタ行の単価をすべて合算」します。
単純な検索（最初の1件）ではない点に注意してください。

### マッチ条件
- **SS400・A6063**：`材質 ＋ 鋼種` が一致する行（表面仕上げは無視）。
- **上記以外（SUS 系など）**：`材質 ＋ 鋼種 ＋ 表面仕上げ` が完全一致する行。

### 単価の値（マスタ）
- SS400 … 250
- A6063 … 800
- SUS 系 … 800

### 重要な再現ポイント
- **SS400 のフラットバー**は単価マスタに **2 行**（ミガキ 250 ＋ 黒皮 250）存在するため、
  SUMIFS で **合算され 500** になります（Excel と一致）。
- 単価が**空欄のマスタ行**（例：`SUS316L|角パイプ|HL`、`SUS310S|丸パイプ(TP-A)|未研`）は
  一致してもマッチ対象にならず、**材料費は空欄**になります。
- 一致が 1 件も無い場合もキロ単価・材料費は空欄になります。

> 実装上の単価マスタは `SUS_PRICED`（SUS 系の単価行）と `PRICE`（全行を組み立てた配列）で
> 表現しています。単価を変えるときはこの 2 つを編集します。

---

## 7. 材料費 cost [円]

```
材料費 = round( 重量[kg] × キロ単価[円/kg] , 0 )
```

- 円未満を四捨五入（整数化）。
- 重量またはキロ単価が空欄なら材料費も空欄。

---

## 8. 検索の一致条件（参考）

在庫検索の絞り込みは、入力された項目ごとに次の判定を行います（空欄の項目は無視）。

- 材質 / 鋼種 / 板厚 / 長さ / 表面仕上げ … **完全一致**
- 材料規格 … **部分一致**（含まれていればヒット。例：「50」で `50*50` 等）

---

## 9. 変更時のチェックリスト

1. 式や単価を変えたら、Excel の既知の計算行（在庫サンプル）と重量・材料費を突き合わせる。
2. とくにキロ単価は「合算（SUMIFS）」「空欄行は不一致」の 2 点を崩していないか確認。
3. 丸め（重量=小数3桁、材料費=整数）を維持しているか確認。

## 追記（2026-09-21）：画像読取データ対応で追加した鋼種

以下は Excel 由来ではなく、紙台帳（画像読取）取込のために**追加**した鋼種。既存の式は一切変更していない。

| 鋼種 | 断面積の式 | 備考 |
|---|---|---|
| 化粧管 / BA管 / 丸パイプ(種別不明) | π/4 × ( Φ² − (Φ−2t)² ) | 丸管系と同一の式 |
| 丸棒 | π/4 × Φ² | 無垢材。板厚は使わない |
| 角棒 | A × B | 無垢材。規格が「10*10」等。板厚は使わない |

比重の追加：アルミ=2.7、ﾁﾀﾝ/チタン=4.51。
これらの鋼種はキロ単価マスタに行が無いため、材料費は空欄になる（単価を決めたら PRICE に追加する）。
